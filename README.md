# KDTouch

Silicon Works SW4101Cを搭載したKD1ディスプレイのタッチ入力を、macOSのクリック・ドラッグ・2本指スクロールに変換するメニューバーアプリです。UPDDは使いません。

## 対応範囲

- macOS 26以降、Apple Silicon。
- USB Vendor ID `29bd` / Product ID `4101`、同梱のHID descriptorと一致するSW4101C。
- macOSが画面名を`KD1`と認識するディスプレイ。画面は横向きで使用します。
- 1本指のタップ・ドラッグ、2本指の縦横スクロール。
- 切り替え可能な1本指スクロールモード。タップはクリック、指を動かすとスクロールします。

画面の位置や解像度はmacOSから取得します。画面名とUSB IDは対応機種の条件であり、特定のMacの画面番号・配置・シリアル番号は使いません。別機種や異なるファームウェアには未対応です。ピンチ、右クリック、3本指以上の操作は実装していません。

## 実装

Swiftで実装し、AppKit、IOKit HID、CoreGraphics / ApplicationServicesを使います。UIはAppKitです。外部ライブラリ、UPDDのコードやライブラリ、独自のシステム拡張は使いません。ネットワーク通信やキーボード入力の取得も行いません。

`Resources/SW4101C.bin`は実機が公開するHID report descriptorです。テストデータはその機器から取得した接点情報で、座標・接点ID・相対scan timeのみを含みます。

## Nixで開発・ビルドする

macOS上でNixのflakes、direnv、nix-direnvを設定してください。`flake.lock`に固定したNixpkgsからSwiftとApple SDKを取得します。ローカルのXcode配置や個人の署名証明書は必要ありません。

repoで`.envrc`を許可すると、nix-direnv経由で開発環境に入ります。環境の構築に失敗したときは、古い環境へ切り替えずにエラーにします。

```sh
direnv allow
./build.sh
```

1コマンドで実行する場合は次を使います。

```sh
direnv exec . zsh ./build.sh
```

入力形式・画面座標・タップ・ドラッグ・キャンセル・2本指スクロールの検証後、`build/KDTouch.app`と`build/KDTouch.zip`を生成します。標準ではad hoc署名を使います。

Nixパッケージとしてビルドする場合は次を使います。検証も同時に実行します。

```sh
nix build
nix flake check
```

アプリは`result/Applications/KDTouch.app`です。`build/`と`result`はGitの対象外です。ビルドにはmacOS標準の`codesign`と`ditto`も使用します。

生成アプリはmacOSの標準ライブラリを使い、実行時にNixストアへ依存しません。

自分の証明書で署名する場合だけ、ビルド時に指定できます。

```sh
KDTOUCH_SIGN_IDENTITY='自分のコード署名証明書名' direnv exec . zsh ./build.sh
```

ad hoc署名で再ビルドした場合は、macOSで権限の再登録が必要になることがあります。配布用のDeveloper ID署名・公証は行っていません。

## 使い方

1. UPDDなど、同じUSB機器を扱うドライバを停止します。UPDDをアンインストールした直後はUSBを抜き差しします。
2. ビルドした`KDTouch.app`をアプリケーションフォルダに入れて開きます。
3. システム設定の「プライバシーとセキュリティ」で、KDTouchの「アクセシビリティ」と「入力監視」を許可します。入力監視を変更したらアプリを再起動します。
4. 確認画面の四隅をタップし、中央の文章を2本指でスクロールします。

確認画面を閉じても、メニューバーのKアイコンで常駐します。メニューから停止・再開・終了できます。KDTouchを終了すると入力変換も止まります。ログイン時の自動起動は登録しません。

Kアイコンのメニューで「1本指でスクロール」をオンにすると、1本指のスワイプで縦横にスクロールできます。このモードでは1本指のドラッグ操作をスクロールに置き換えます。タップによるクリックと2本指スクロールは引き続き使えます。設定はアプリの再起動後も保持します。初期設定はオフです。

停止時には機器を元のマウス互換モードへ戻します。KD1を取り外したため停止した場合は、再接続後に「タッチを開始」を選びます。

- [x] 2本指で確認画面をスクロールできる。
- [x] 1本指スクロールモードで、タップによるクリックとスワイプによるスクロールを実機で確認する。

### テスト完了条件

- [x] 実機入力のサンプルを読み取れる。
- [x] 不正な長さ・範囲外の座標・重複した接点IDを拒否する。
- [x] 座標変換、タップ、ドラッグ、キャンセル、2本指スクロールの自己検証が通る。
- [x] 1本指スクロールと、操作中のモード変更で余計なクリックや押しっぱなしが発生しない自己検証が通る。
- [x] アプリの再起動後に1本指スクロールの設定が保持されることを確認する。
- [x] 停止後の再開で接続済み機器を取得できることを実機で確認する。
- [x] nix-direnv経由の`direnv exec . zsh ./build.sh`で検証とビルドが通る。
- [x] `nix build`と`nix flake check`が通る。

### 運用反映条件

- [x] 検証機のアプリケーションフォルダへ導入する。
